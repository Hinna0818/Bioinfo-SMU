# 大三课程

**学年概述**：大三是生物信息学专业核心课程学习的关键阶段。

---

## 学期内容

::: {.panel-tabset}

### 大三上学期

专业核心课程深入学习阶段。重点掌握：高性能计算导论、高通量测序技术、生物信息学导论、生物信息学统计方法、生物信息学应用语言。

**大三上学期是南方医生信第一次接触到专业课，所以非常重要，请各位一定要认真对待！**

### 大三下学期

专业知识综合应用与实践。重点掌握：基因组学、机器学习、生物药剂学与药物动力学、细胞信号转导、蛋白质组学等。

:::
