# 毕业论文指南

本页面用于整理生物信息学专业毕业论文相关流程，帮助同学按时间节点完成选题、开题、论文撰写、查重、答辩与归档。具体时间和材料要求以学院、教务系统和指导老师通知为准。

---

## 毕业论文时间 timetable

毕业论文通常贯穿大四学年。建议把任务拆成“确认方向、完成研究、撰写论文、准备答辩、提交归档”五个阶段。

| 阶段 | 建议时间 | 核心任务 | 产出材料 |
|:--|:--|:--|:--|
| 方向准备 | 大四上学期9月-10月 | 了解研究方向，联系潜在指导老师，阅读近年论文与课题组工作 | 初步选题意向、文献清单 |
| 选题确认 | 大四上学期10月-12月 | 与指导老师确定论文题目、研究问题、数据来源与技术路线 | 选题登记、任务书或开题准备材料 |
| 开题与方案细化 | 大四上学期末至寒假前后 | 明确研究背景、研究目的、方法路线、预期结果和风险预案 | 开题报告、PPT、时间计划 |
| 数据分析与实验推进 | 大四下学期前半段 | 获取和整理数据，完成主要实验或计算分析，记录关键参数和结果 | 分析脚本、结果图表、阶段性汇报 |
| 初稿撰写 | 大四下学期中期 | 完成摘要、引言、方法、结果、讨论和参考文献 | 论文初稿、图表初版 |
| 修改与查重 | 答辩前 2-4 周 | 根据老师意见修改论文，检查格式、引用、图表和重复率 | 论文定稿、查重报告、答辩申请材料 |
| 答辩准备 | 答辩前 1-2 周 | 制作答辩 PPT，准备问题清单，进行模拟答辩 | 答辩 PPT、讲稿、备用材料 |
| 答辩与归档 | 学院统一安排 | 完成现场或线上答辩，根据答辩意见修改并提交最终版本 | 最终论文、答辩记录、归档材料 |

::: {.callout-note title="毕业设计重要事务！！！"}
1. 大四上学期开学大概9月中旬班群会发一个共享文档，里面会让填实习单位，这个实习单位过往大部分同学都是填的课题组，也有少部分填公司。在公司实习的，毕业论文可以挂载到我们学校的某个老师上。实习单位就是指导你完成毕业设计的单位。  
2. 对于实习单位为课题组的同学，大部分同学会在本校实习，小部分同学会在外校课题组实习。
3. 毕业设计的整个时间线分别为：确认选题与指导老师（大四上）、开题报告提交（来年3月左右完成）、中期检查（来年4月左右完成）、第一次查重（来年5月上旬完成）、答辩ppt制作、正式答辩（一般基础医学院毕业班答辩统一在来年5月的最后一个周五）、第二次查重与终稿提交。
4. 关于毕业设计评分，提交答辩稿会先派送给同学院的两位老师进行打分，然后正式答辩那天，会有1个答辩组长（Y叔）+5名答辩组员老师共同打分；答辩组长的评分不计入总分，5个答辩老师打的分会区一个平均分算到成绩单上，作为毕业设计总分。这里要注意，某些保研的学校明确要求毕业设计分数不能低于80分。
:::

### 每周推进节奏

1. 每周至少向指导老师同步一次进展，哪怕只是说明当前卡点。
2. 所有代码、图表和数据处理步骤都保留版本，避免后期无法复现。
3. 论文写作尽早开始，方法部分和数据来源可以边做边写。
4. 每次修改论文前另存版本，文件名中加入日期。

## 毕业论文选题与指导老师

毕业论文选题应同时满足三个条件：自己能持续推进、指导老师能提供有效指导、在毕业论文周期内可以完成。

### 选题方向

生物信息学方向的毕业论文常见选题可以分为以下几类：

| 类型 | 适合内容 | 常见产出 |
|:--|:--|:--|
| 公共数据库分析 | TCGA、GEO、UK Biobank、单细胞或空间转录组数据分析 | 差异分析、富集分析、预后模型、分型结果 |
| 方法复现与比较 | 复现一篇论文的方法，比较不同工具或参数 | 流程复现、性能对比、适用场景总结 |
| 生物信息学流程构建 | 整理某类数据的标准分析流程 | 可运行脚本、流程图、示例结果 |
| 实验数据辅助分析 | 配合课题组实验数据完成统计和可视化 | 质控结果、核心图表、统计分析 |
| 数据库或工具开发 | 构建轻量网站、脚本包或可视化工具 | 工具原型、使用说明、测试案例 |

### 如何判断题目是否合适

::: {.callout-tip title="选题检查清单"}
- 数据是否已经可获取，或能在开题后较快获得？
- 研究问题是否能用一两句话说清楚？
- 是否有明确的主要图表，例如差异分析图、热图、网络图、生存曲线或流程图？
- 是否能在 8-12 周内完成主要结果？
- 题目是否避免过大，例如“癌症机制研究”应收敛为具体癌种、数据集、基因集或分析问题？
:::

### 联系指导老师

联系老师前，建议准备一页简短材料，说明自己的兴趣方向、已掌握技能、想做的问题和可投入时间。

可以包含：

- 自己熟悉的技能：R、Python、Linux、统计分析、机器学习、转录组分析等。
- 感兴趣方向：肿瘤组学、单细胞、空间转录组、药物筛选、流行病学数据库等。
- 已读文献：列 2-3 篇与方向相关的论文。
- 初步想法：可以是一个很粗的题目，但要说明数据来源和分析路线。

### 与指导老师确认的事项

| 问题 | 为什么重要 |
|:--|:--|
| 论文题目是否需要调整 | 保证题目范围适中，符合专业培养目标 |
| 数据来源是否可靠 | 避免后期数据拿不到或权限不足 |
| 技术路线是否可完成 | 避免使用自己短期内无法掌握的方法 |
| 汇报频率如何安排 | 保证进度可控，减少临近答辩集中返工 |
| 图表和结果标准 | 提前对齐老师对论文质量的要求 |

## 毕业论文答辩

答辩的核心不是把论文逐字讲完，而是在有限时间内说明：你研究了什么问题，为什么值得做，怎么做，得到了什么结果，结果有什么意义和局限。

### 答辩 PPT 结构

建议控制在 5-6 分钟，具体以学院要求为准。2026届答辩时常明确要求每个人控制在5分钟以内，回答问题时常控制在3分钟以内。

| 部分 | 建议页数 | 内容重点 |
|:--|:--:|:--|
| 标题页 | 1 | 论文题目、姓名、专业、指导老师 |
| 研究背景 | 1-2 | 领域问题、研究意义、已有工作不足 |
| 研究目的 | 1 | 明确本文要回答的问题 |
| 数据与方法 | 2-3 | 数据来源、样本量、分析流程、关键工具 |
| 主要结果 | 4-6 | 按逻辑展示核心图表，不堆砌所有结果 |
| 讨论与局限 | 1-2 | 结果解释、可靠性、局限和后续方向 |
| 总结 | 1 | 用 3-4 条概括主要结论 |

### 答辩前检查

::: {.callout-warning title="答辩材料检查"}
- PPT 中所有图表都应清晰可读，坐标轴、图例和字体大小统一。
- 数据来源、样本量、筛选标准和统计方法要能说清楚。
- 所有缩写第一次出现时应解释。
- 论文题目、学生姓名、指导老师姓名不要写错。
- 准备一个 PDF 版本，避免现场字体或格式错乱。
:::

### 常见问题准备

答辩老师常问的问题通常集中在以下方面：

1. 为什么选择这个题目？
2. 数据从哪里来，样本量是多少，纳入排除标准是什么？
3. 为什么选择这个分析方法，而不是其他方法？
4. 你的核心结果是否可靠，是否做了验证？
5. 图中的分组、颜色、统计检验和显著性标注是什么意思？
6. 论文最大的创新点或价值是什么？
7. 目前研究有什么局限，后续如何改进？

### 答辩表达建议

- 先讲主线，再讲细节。不要一上来解释所有参数。
- 每张结果图只强调一个结论。
- 遇到不会的问题，说明自己的理解和后续可以补充的方向，不要硬编。
- 回答问题时先给结论，再解释依据。

### Q&A
1. 毕业设计单位可以修改吗：
A： 可以修改，需要填资料申请；若是本校，则不需要；

2. 答辩还有哪些需要注意的？
A：答辩前2-3天班长会在群里发抽签顺序，每个人都会随机分配到不同的位次；答辩当天分为上午+下午两个半场，所有人需要穿正装，早上8点开始，答辩完的同学可以先走，可以等到快答辩时再过去现场；

::: {.callout-note title="归档原则"}
最终提交前，确保论文、PPT、代码、核心图表和源数据能够对应起来。毕业论文不是只交一个 Word 文件，后续复查或修改时，可复现的材料会非常重要。
:::
